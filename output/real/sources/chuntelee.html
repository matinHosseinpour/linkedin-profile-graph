    🌙 Moonshot AI just released Kimi-K3.1-Pro on Hugging Face. Here are some interesting facts about it 👇

    🐘 It's huge, and sparse
    → 2.8T total parameters, but only 104B active per token
    → Along with Kimi-K3, it's the largest real model release on the Hub. The next biggest are Qwen3.8-2.4T and DeepSeek-V4-Pro (1.6T)
    → 896 experts, with 16 picked per token. That's ~2× more than DeepSeek-V4-Pro and 7× more than Mistral-Large-4

    🧠 Clever attention for a 1M-token context
    → Most of its 93 layers use linear attention (KDA). Every 4th layer uses DeepSeek-style sparse attention, which only looks at the top 2048 tokens
    → That's how it handles a 1M-token context, on par with the other frontier open models
    → It uses a custom activation (SiTU-GLU) and a 401M-parameter vision encoder (MoonViT-V2), so it takes both text and images

    💾 Small on disk for its size
    → It was trained to run in 4-bit (MXFP4), so the whole repo is only ~1.56 TB
    → Stored in regular BF16, it would be about 5.6 TB (!)

    📊 Benchmarks (from the model card)
    → It goes back and forth with Claude Opus 5.5 and GPT-6 Astra, and tops the table on BrowseComp (92.1), HLE with tools (70.0) and SWE Marathon (51.7)
    → It's weaker on pure reasoning without tools and on cyber security
    → Fun fact: Moonshot ran most of their own coding evals using the Claude Code harness

    📜 License (a modified MIT)
    → Free to use, modify and redistribute
    → API businesses making over $20M a year need a deal with Moonshot
    → Products with over 100M monthly users or over $20M monthly revenue must display "Kimi K3.1-Pro"

    🤗 On the Hub
    → It went public ~1.5 hours ago and already has 214 likes, about 9× Kimi-K3's first hour. It's #19 on trending
    → It isn't gated, but loading it in transformers requires trust_remote_code

    Open weights at the frontier keep getting bigger and more efficient. Check it out:
    https://lnkd.in/dKUWx4_i
